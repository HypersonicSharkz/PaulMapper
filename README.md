# Paul MApper

Paul Mapper is a ChroMapper tool for creating poodles, using selected Notes, Bombs, and Walls.

## Installation
1. Download the latest release
2. Unzip the content into your chromapper/plugins folder


## Quick Start
Start creating a poodle by selecting two or more notes, then pressing the *Create Poodle* button ***(F12 by default)***.

This works for both Notes, Bombs, and Walls.

Selected Notes | After pressing *Create Poodle*
:-------------------------:|:-------------------------:
![alt text](image-12.png) | ![alt text](image-11.png)

You can now modify the shape of the poodle by dragging around the spheres (Curve Points). Each note in the original selection will be converted into a curve point. 
More points can be added between the first and last by pressing the *Add Anchor Point* button ***(H by default)***.

To finish editing the poodle, unselect everything by pressing ***Crtl+A***.

>[!NOTE]
> The density, and other settings can be changed in the [Paul Mapper Menu](https://github.com/HypersonicSharkz/PaulMapper/wiki/Menu).
